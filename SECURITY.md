# Security and privacy

Relay uses existing local Codex authentication. Do not share credentials, local databases, or raw private conversation snapshots in issues.

Goal Accessibility control can navigate and operate Codex windows. Enable it only when you want Relay to manage selected Goals. The helper rejects unverified targets and does not retry uncertain submissions automatically.

For a sensitive report, contact the maintainer through the GitHub profile rather than posting secrets publicly. Relay is an independent local tool and has no OpenAI affiliation or endorsement.
